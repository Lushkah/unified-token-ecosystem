# Unified Token AI Ecosystem 🤖⚡

A comprehensive, production-ready platform combining intelligent AI agents, blockchain security, and advanced token economics for autonomous ecosystem development.

## 🎯 Overview

This unified platform merges two powerful ecosystems:
- **Token AI Ecosystem**: Self-building platform with autonomous agents
- **AI Token Ecosystem**: Blockchain-based token economy with security

### Core Vision

Create a self-sustaining, decentralized ecosystem where:
- **AI Agents** autonomously develop, test, and optimize systems
- **Blockchain** ensures secure, immutable transactions and verification
- **Token Economics** drive agent behavior and community participation
- **Self-Evolution** enables continuous improvement without human intervention
- **AI Security** protects against threats with advanced anomaly detection

## 🚀 Quick Start

### Prerequisites
- Python 3.10+
- Node.js 18+
- Docker & Docker Compose
- PostgreSQL 14+
- Redis 7+
- Web3 wallet (MetaMask, WalletConnect, etc.)

### Installation

```bash
# Clone the repository
git clone https://github.com/Lushkah/unified-token-ecosystem.git
cd unified-token-ecosystem

# Install Python dependencies
pip install -r requirements.txt

# Install Node dependencies
npm install

# Set up environment
cp .env.example .env
# Edit .env with your configuration:
# - Database credentials
# - Blockchain RPC endpoints
# - API keys (OpenAI, etc.)
# - Token contract addresses
# - Wallet configuration

# Start services with Docker
docker-compose up -d

# Initialize database
python scripts/init-db.py

# Deploy smart contracts (testnet)
python scripts/deploy-contracts.py --network=sepolia

# Start the platform
python main.py
```

### Access the Platform

- **API Documentation**: http://localhost:8000/docs
- **Admin Dashboard**: http://localhost:3000
- **Wallet Connection**: MetaMask (configured in UI)
